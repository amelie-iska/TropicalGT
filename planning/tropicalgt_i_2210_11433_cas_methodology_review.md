# TropicalGT-I CAS Methodology Review for `references/2210.11433v1.pdf`

Date: 2026-06-14
Branch: `tropicalgt-i-real-cas-no-proxy-20260614`
Primary objective: replace informal algebra diagnostics with certified computer-algebra computations for the 2-parameter persistence modules attached to graph-of-thought trajectories.

## Paper Scope

The paper studies multiparameter persistence modules through multigraded commutative algebra. A finite `N^n`-indexed persistence module is treated as a finitely generated `K[x_1, ..., x_n]`-module. For TropicalGT-I the relevant case is the bifiltration by reasoning level and radius, so the working ring is

```text
S = F2[x_level, x_radius].
```

The key point for our implementation is that the module is not just a grid of Betti numbers. It consists of vector spaces at bidegrees `(level, radius_grade)` and structure maps induced by inclusions. The algebraic object is the resulting multigraded `S`-module, together with presentations, rank invariants, Fitting ideals, minors, and when available minimal multigraded free resolutions.

## Definitions to Use in TropicalGT-I

1. **Bifiltered graph-of-thought object**
   - For a trajectory `T`, each reasoning level `ell` and radius grade `r` gives a simplicial complex `K_(ell,r)`.
   - Radius grades are the sorted exact radii at which simplices enter the filtration.
   - The level order is the reasoning-growth order of the trajectory.
   - Every nonempty trajectory must emit this bifiltration. Absence is an error state for empty or invalid input only.

2. **Persistence module over `F2[x_level,x_radius]`**
   - The fiber is `H_i(K_(ell,r); F2)`.
   - Multiplication by `x_level` is the inclusion-induced structure map from `(ell,r)` to `(ell+1,r)`.
   - Multiplication by `x_radius` is the inclusion-induced structure map from `(ell,r)` to `(ell,r+1)`.
   - These maps are computed over `F2` by `rank(B_target + image(Z_source)) - rank(B_target)`.

3. **Free chain presentation**
   - The chain groups `C_i` are multigraded free `S`-modules generated by simplices at their first bidegree.
   - Boundary maps are monomial matrices with signs reduced over `F2`.
   - This is a real chain presentation, not a free resolution of homology.

4. **Actual free resolutions**
   - A minimal multigraded free resolution may only be rendered when a CAS backend certifies exactness, minimality, and multidegree shifts.
   - Accepted backends: Macaulay2, SageMath, Singular, or another verifiable CAS path.
   - Ungraded or total-graded CAS output is real CAS output, but it is not a multigraded persistence-module resolution and must not be labeled as one.

5. **Rank invariants and determinantal ideals**
   - For bidegrees `u <= v`, the rank invariant is the rank of the induced map `M_u -> M_v`.
   - The paper interprets rank conditions as determinantal varieties. In implementation, the actual matrix of a structure map or presentation map must be sent to CAS for minors/ideals.

6. **Fitting ideals**
   - Given a finite presentation `F -> G -> M -> 0`, `Fitt_j(M)` is generated by the appropriate minors of the presentation matrix.
   - Fitting ideals commute with base change and are stable invariants for comparing modules.
   - For TropicalGT, Fitting ideals are CAS computations on the actual presentation matrix over `F2[x_level,x_radius]`.

7. **Buchsbaum-Eisenbud multipliers**
   - The paper uses Buchsbaum-Eisenbud multipliers to study varieties of complexes and relations among minors.
   - Implementation should evaluate `amelie-iska/BEMultipliers` and Macaulay2 packages only after a certified complex/resolution is available.
   - BE diagnostics are not to be inferred from rank tables alone.

8. **Varieties of complexes**
   - The paper studies schemes cut out by equations `d_i d_{i+1}=0` plus rank/minor conditions.
   - TropicalGT can attach these to the chain complex of a trajectory: boundary composition zero is exact algebra, and rank conditions can be sent to CAS.
   - This supports research figures showing coordinate rings, minors, and degeneration conditions.

9. **Standard monomial / Young-tableaux structure**
   - The paper develops standard monomial theory for coordinate rings generated by minors and BE multipliers.
   - TropicalGT should not fabricate this structure. It can be used when the CAS output includes the relevant minors/multiplier variables and relations.

## Implementation Commitments

### Immediate CAS additions

1. Add actual Fitting/minor diagnostics for the presentation matrix whenever a CAS backend can compute them.
2. Persist CAS output separately from chain-presentation diagnostics.
3. Render Fitting ideals, minors, and presentation matrices in a Macaulay2/Singular-style table.
4. Add tests that a backend result cannot be promoted to multigraded resolution unless it includes multidegree shifts and explicit certificate metadata.
5. Add tests that unavailable CAS outputs render as unavailable, not as inferred values.

### Next certified-resolution path

1. Prefer Macaulay2 for multigraded `F2[x_level,x_radius]` resolutions and Fitting ideals.
2. Use Singular/Sage for real total/ungraded or matrix/minor diagnostics when Macaulay2 is absent, but never relabel them as multigraded free resolutions.
3. If Macaulay2 is unavailable on the machine, keep the implementation ready and render exact missing-backend status until installation is available.
4. Once Macaulay2 exists, run the actual `res`, `dd`, `fittingIdeal`, `minors`, and optional `BEMultipliers` commands on the generated presentation.

### Visualization changes

1. The bivariate module page should include Miller-Sturmfels-style staircase diagrams for actual multidegree antichains.
2. Coordinate axes should use one dimensional cone(s) terminology where appropriate.
3. Fiber-rank surfaces should remain separate from chain-module staircase diagrams.
4. Free resolutions, Fitting ideals, minors, BE multipliers, and derived comparison panels should use research-figure layout: matrix blocks, degree shifts, Betti tables, and commutative diagrams.

### Training and inference use

1. Fitting ideals and rank invariants can become metrics/regularizers only after they are computed as actual CAS outputs or exact finite-field matrix computations.
2. Analogical retrieval may use these invariants as memory filters: compare rank invariants, Fitting ideals, and certified resolution summaries before accepting a memory analogy.
3. Derived similarity may only be computed from certified chain maps/resolution maps or exact invariants. Otherwise it must report unavailable.
4. These outputs remain optional at inference time because CAS calls can be expensive.
